# Submission checklist

Owner must complete this after implementation verification. Do not mark an item complete without opening the public artifact from a logged-out/private browser.

## Repository

- [ ] Public GitHub repository; no participant-authored commit before 2026-08-12.
- [ ] Complete source and fixtures; no secrets, private data, payloads, generated dependency folders, or local HydraDB state.
- [ ] OSI-approved `LICENSE` file.
- [ ] README includes problem, product, screenshots/GIF, architecture, exact setup, seed/run/test commands, HydraDB role, known limits, and attribution.
- [ ] `.env.example` documents every required value with safe placeholders.
- [ ] Fresh-clone instructions work on a second machine or clean directory.
- [ ] Third-party packages and incident/dataset sources attributed.
- [ ] Five golden outcomes shown in README or linked test output.

## Product proof

- [ ] HydraDB write/read/path round trip works from a clean seed.
- [ ] Baseline shows checkout confirmed, admin current-only/unknown as specified, analytics safe.
- [ ] Every impacted result opens an exact evidence path.
- [ ] Query inspector shows genuine HydraDB execution.
- [ ] Replay reduces two impacted services to zero and leaves baseline intact.
- [ ] No live OSV/deps.dev/network dependency during demo.

## Video, maximum 3:00

- [ ] Duration at most 2:50 target and never above 3:00.
- [ ] Problem, working product, HydraDB role, temporal honesty, replay, and vision shown.
- [ ] Text remains readable at 1080p.
- [ ] Link is accessible without requesting permission; unlisted YouTube is acceptable.
- [ ] Backup local recording retained.

## Form

- [ ] Project name and short description.
- [ ] Problem and what was built.
- [ ] Deployed link if stable; otherwise omit rather than submit a broken link.
- [ ] Meaningful HydraDB use.
- [ ] Tech stack.
- [ ] Every team member and contribution.
- [ ] Public repository link.
- [ ] Demo video link.
- [ ] Submit before 2026-08-21 06:59 UTC; keep a large buffer.
